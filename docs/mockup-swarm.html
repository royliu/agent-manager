agent-manager · PRD and mockup · draft v0.3 · 6 September 2026

am swarm

Go to a project, start a General Manager on one of your profiles, give it a name. It brings up its own task manager and four task agents. You talk to it and you watch the board.

What you see
Friday, the General Manager

A Claude Code session on your profile. Interprets, discusses, breaks work into tasks, assigns, reviews. Owns the workspace and the team.

am gm start personal friday
The board

Every task with status, owner, ETA and cost. A team strip with each agent's state and context use. How many things need you.

am board
What runs underneath
Task manager

A board on the surface, an agent underneath. Keeps tasks, notes, questions, runs and the project brief; assigns work to idle agents; watches for stalls and context limits. Answers the team's questions on Friday's behalf, reasoning from your intent, so Friday stays in the conversation with you.

friday-1 … friday-4

Persistent agents on the same profile, one task at a time. Report with evidence, ask with context, checkpoint to the board and compact at 90%.

Mockup · am gm start

Starting Friday in a project

One command, from the shell rather than from inside Claude Code: the profile, credentials, tools and status line are chosen when Claude Code launches. am sets up the team, then hands the terminal to Claude Code (or Codex, if that is the profile's tool) running as Friday. It does nothing else. The board is am board in another terminal.

Interactive mockup · am board

The board

Click into the terminal. Arrows move, ⏎ opens a task, g regroups by status, agent or ETA. #11 is waiting on you: press r and answer. #10 is a plan waiting for approval: a starts it on the idle agent. The mouse works too: wheel or trackpad scrolls the column under the pointer, a click selects a card, a double-click opens it.

    PRD · the three rules
    
Who talks to whom, in plain English, without losing the thread

  

  
  

    

      
2 · Plain English, and every question carries its context

      
No jargon or internal names; the only shorthand is task ids, file paths and commands. The task manager refuses a question missing any field below. Reports must say what changed, how it was verified, what is left. Friday holds itself to the same rule with you.

      

        
about
which task this is and what it is for

        
known
what has been done, found or tried so far

        
question
the exact question

        
options
the choices considered, each with its trade-off

        
default
what the agent will do if no answer arrives, and by when

      

    

    

      
3 · Checkpoint at 90%, then compact

      
    
        
  1. Watch. Each agent, Friday included, watches its context; the task manager shows it on the team strip.
    2. 
        
  2. Checkpoint. At 90% the agent writes a note on its task: done, left, next, decisions and why.
    3. 
        
  3. Compact, then continue from the note. The board is the memory; nothing important lives only in a window. Each agent also keeps a one-paragraph memory note for the project.
    4.

    Decisions
    
Where the design departs from the brief

  

  

    
The task manager is a board on the surface and an agent underneath

    
Bookkeeping, assignment and watching are deterministic. Answering the team is an agent: a persistent conversation on the same profile with read-only access to the workspace, reasoning from the project brief and everything recorded, deciding the way Friday would. Only the rare judgment call reaches Friday, so Friday stays with you.

    
Agents are persistent team members

    
Four named agents with project memory, not a process per task. This is what makes the 90% rule necessary and visible.

    
You set the workspace; Friday carries it

    
The folder and shell you start from become the workspace brief in every assignment. Friday may give a task its own worktree when two agents would otherwise edit one checkout, and says so on the task.

    
All agents on Friday's profile by default

    
Five sessions on one Pro plan will hit the 5-hour window. Friday warns at 80% and offers to move an agent to another profile.

    
Plain English is enforced by tool schema

    
Required fields on questions and reports work every time; a prompt rule works most of the time.

  






  

    Roadmap and open questions
    
Four milestones, each with a demo

  

  

    
M1
Start
am gm start, four agents, board read-only, report
Friday says hello; one ask becomes a task an agent finishes.

    
M2
Conversation
structured ask with pause and resume, escalation, board keys, notes in briefs
An agent's question reaches you on the board; you answer; it finishes.

    
M3
Team
team strip, checkpoint and compact at 90%, memory notes, workspace propagation, watchdog, cost per task
friday-2 hits 90%, checkpoints, compacts, finishes. You change branch in chat; the next task uses it.

    
M4
Polish
quota guard and agent move, triage, notifications, --json
Daily-driver quality.
